# 物候 WUHOU — 線上商店示範

一間虛構器物選物店的完整購物流程。**可以真的操作**：選規格、加入購物袋、改數量、走完結帳。

**▶ [打開來玩](https://vicentelo0227.github.io/wuhou-demo/)**

![商品列表](docs/shop.jpg)

---

## 這是什麼

給客戶看的「預售屋」——在沒有後端的情況下，把一個購物網站在使用者手上會碰到的每一個環節都做成真的。

所有狀態存在瀏覽器的 `localStorage`：關掉分頁明天回來，購物袋還在。唯一沒有的是真的扣款和把訂單存進資料庫，那正是要收錢才做的部分。

**沒有任何資料離開你的瀏覽器。** 沒有後端、沒有分析追蹤、沒有第三方請求（除了 Google Fonts）。

## 做了哪些互動

這些不是憑感覺設計的，是拆解 Apple、Google Store、Dyson、Amazon、LV、Aesop 等站的實際做法之後決定的。

| | |
|---|---|
| **漸進式解鎖** | 規格不預選；選完之前「加入購物袋」按鈕**不存在於 DOM**（不是變灰）。強迫使用者對每個維度做主動選擇，避免事後「我沒注意到選了這個」 |
| **價格即時鎖定** | 未選規格顯示「NT$2,480 起」，選定後變精確價，瀏覽器分頁標題同步更新成含規格的字串 |
| **兩種缺貨語意** | 「暫時缺貨（可登記通知）」與「此規格不生產」是兩種不同文案與行為。缺貨選項**仍可點選、選了才說明原因**，不隱藏也不停用 |
| **圖片欄 sticky** | 桌面版往下看規格時商品圖固定在視野內（Amazon 的做法） |
| **手機固定購買列** | 商品頁很長，滑到下面才想買時不必滑回頂端 |
| **相容加購** | 加入購物袋後，抽屜裡推薦與該商品相容的配件（Dyson 的高轉換時機） |
| **運費提早揭露** | 購物袋就顯示運費與免運進度條。Baymard 統計「額外費用超出預期」是放棄結帳的第一大原因，佔 40% |
| **訪客結帳** | 三步驟，第一步沒有登入關卡。表單約 12 個元件，接近 Baymard 的理想值 |
| **留著以後買** | 商品移出購物袋但不刪除 |
| **篩選收成一顆按鈕** | 商品只有六件，不需要 Amazon 那種側邊常駐篩選欄 |

## 關於付款

信用卡那一步**不會出現卡號欄位**。真實專案這裡會嵌入金流商（綠界／藍新／Stripe）提供的安全欄位，卡號不經過自己的網站——這是 PCI 的要求，也是我不會在示範站上假裝有的東西。

## 技術

原生 HTML / CSS / JavaScript，**沒有框架、沒有建置流程**，`git push` 就是部署。

```
index.html      首頁
shop.html       商品列表（篩選、排序）
product.html    商品詳情（?id=...）
cart.html       購物袋
checkout.html   結帳三步驟
done.html       訂單完成
js/data.js      商品資料
js/store.js     購物車狀態與 localStorage
js/ui.js        頁首、抽屜、商品卡
css/site.css    設計系統
```

全站 676 KB（含全部商品照片）。`localStorage` 的讀寫都包在 `try/catch` 裡——無痕視窗會直接丟例外，包起來才不會整頁掛掉。
